# Synthrophy Chat (unofficial build)

A rebranded build of the open-source Nextcloud Talk Android app for Synthrophy Office by LegitShield. It is **not** made, endorsed or supported by Nextcloud GmbH.
Licence: GPL-3.0-or-later, exactly as upstream (see LICENCE.md). Upstream copyright notices are kept. Our changes are branding only, produced by
`nextcloud/clients/android/brand-chat.mjs` in https://github.com/legit-shield/synthropy-office, applied to upstream tag v25.0.2:
application id com.synthrophy.office.chat, name, icons, colours, fixed server https://office.synthrophy.com, push notifications off, original project's Firebase settings removed.
The database encryption key in setup.xml is a placeholder in this repository; builds inject their own key.
